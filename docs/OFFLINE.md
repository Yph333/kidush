# הפעלה מקומית ובלי אינטרנט

האתר כולו רץ במחשב שלך. כל הנתונים נמצאים בתוך הפרויקט: טקסט הרמב״ם, הגופנים, המפות, נתוני הגובה, תמונות הירח וכדור הארץ וטבלאות הכוכבים. בזמן השימוש האתר לא פונה לרשת בכלל. זה נבדק על כל השקפים, במצב חקירה ובמצב מצגת, בדפדפן שהרשת שלו מנותקת: אפס פניות לרשת ואפס שגיאות, כולל שקפי התלת־ממד והמפות. אפשר לחזור על הבדיקה בכל רגע עם `npm run check:offline` (צריך את דפדפן הבדיקות).

צריך אינטרנט **פעם אחת בלבד**, כדי להוריד את הפרויקט ואת החבילות שלו. מאותו רגע הכול עובד בלי חיבור.

## החבילה המלאה: הכול בתיקייה אחת

זו הדרך למחשב שאין בו אינטרנט בכלל. מורידים קובץ ZIP אחד, ובו כל הפרויקט עם **כל הספריות כבר מותקנות**:
- `node_modules`: כל הספריות, כולל החלקים המיוחדים ל־Windows.
- `.browsers`: דפדפן הבדיקות.
- `dist-single\index.html`: האתר בנוי כקובץ אחד.
- `dist`: האתר בנוי כתיקייה.

על המחשב הלא מקוון צריך להתקין **רק את Node.js** מקובץ ההתקנה שמביאים איתך. אין שום הורדה נוספת.

**מאיפה מורידים את ה־ZIP** (פעם אחת, במחשב עם אינטרנט):
- **הגרסה האחרונה:** https://github.com/Yph333/kidush/releases/latest/download/luach-offline-windows.zip
  GitHub בונה אותה מחדש אוטומטית בכל מיזוג ל־main, בודק אותה (בדיקות היחידה, ואז כל השקפים בלי רשת) ומפרסם אותה ב־Releases.
- **או לבנות לבד:** במחשב Windows עם אינטרנט, לחיצה כפולה על `make-offline-package.bat`. בסוף נוצר `luach-offline-windows.zip` בתיקיית הפרויקט.

**על המחשב הלא מקוון:**
1. מתקינים את Node.js מקובץ ההתקנה, גרסה 22 LTS ל־Windows x64 (`node-v22.x.x-x64.msi`). מתאימה גם גרסה 24, או 20.19 ומעלה.
2. מחלצים את ה־ZIP לתיקייה, למשל `C:\luach`.
3. **לשימוש:** לחיצה כפולה על `dist-single\index.html`, או על `start.bat` כדי להפעיל מהקוד.
4. **לבנייה מחדש אחרי שינוי:** `build-single.bat`.
5. **לבדיקה שהכול שלם:**
   - `install.bat` רק מוודא שכל הספריות נמצאות, ולא מוריד כלום.
   - `check-offline.bat` פותח את כל השקפים בלי רשת ומדווח אם משהו חסר.

את החבילה בונים ל־Windows במיוחד. חלק מהספריות (מנוע הבנייה של Vite ומנוע ה־CSS) כוללות קבצים שמתאימים רק למערכת הפעלה אחת, ולכן אי אפשר להעתיק `node_modules` ממחשב Linux או Mac.

## מה להתקין

### חובה (פעם אחת)
| מה | למה | מאיפה |
|---|---|---|
| **Node.js**, גרסת LTS (‏22 או 24, לפחות 20) | לבנות את האתר ולהפעיל אותו | https://nodejs.org (בהתקנה משאירים את ברירות המחדל) |
| **דפדפן עדכני**: Chrome, Edge או Firefox | להציג את האתר | בדרך כלל כבר מותקן |

בדפדפן צריכה להיות **האצת חומרה** פעילה, כדי שהתלת־ממד יעבוד. ב־Chrome וב־Edge: הגדרות ← מערכת ← "השתמש בהאצת חומרה כשאפשר". אם היא כבויה, האתר מציג אוטומטית גרסה דו־ממדית.

### רשות
| מה | מתי צריך | איך |
|---|---|---|
| **Git** | כדי להוריד עדכונים (`git pull`) במקום להוריד ZIP מחדש | https://git-scm.com |
| **דפדפן הבדיקות** (Playwright Chromium) | רק ל־`npm run e2e`, צילומי המסך האוטומטיים | `install.bat` מתקין אותו, או `npx playwright install chromium` |
| **Java (JDK 17 ומעלה)**, ואת הקובץ `zmanim-2.5.0.jar` של KosherJava בתוך `tools/kosherjava/lib/` | רק ל־`npm run oracle:zmanim`, יצירה מחדש של נתוני ההשוואה של זמני היום | https://adoptium.net ; את ה־jar מורידים מ־KosherJava |

**לא צריך:** שרת, מסד נתונים, חשבון בשירות כלשהו או מפתחות API.

הכלים `npm run horizons`, `npm run sources:rambam` ו־`node tools/terrain/build-terrain.mjs` מורידים נתונים מהרשת, אבל רק כדי לבנות מחדש קבצים שכבר נמצאים בפרויקט. בשימוש רגיל לא מריצים אותם.

## צעד אחר צעד (Windows)

**פעם אחת, עם אינטרנט:**
1. מתקינים את Node.js.
2. מורידים את הפרויקט. אחת משתי דרכים:
   - ב־GitHub: Code ← Download ZIP, ואז מחלצים לתיקייה.
   - בשורת הפקודה: `git clone https://github.com/Yph333/kidush.git`
3. בתיקיית הפרויקט: לחיצה כפולה על **`install.bat`**. הוא מתקין את כל החבילות לתיקייה `node_modules`.
4. לחיצה כפולה על **`build-single.bat`**. נוצר הקובץ `dist-single\index.html`.

**מכאן והלאה, בלי אינטרנט**, יש שתי אפשרויות:
- **הקובץ היחיד:** לחיצה כפולה על `dist-single\index.html`. זה כל האתר בקובץ אחד, בערך 4.5MB. אפשר להעתיק אותו לדיסק און קי או למחשב של הכיתה. במחשב הזה לא צריך להתקין כלום, אפילו לא Node.js.
- **השרת המקומי:** לחיצה כפולה על **`start.bat`**. השרת עולה ופותח את האתר בדפדפן. כך גם רואים מיד שינויים בקוד. השרת נסגר לבד כשסוגרים את הלשונית.

## Mac או Linux
אותם צעדים, בשורת הפקודה בתיקיית הפרויקט:
```
npm install                      # פעם אחת, עם אינטרנט
npx playwright install chromium  # רשות: רק לבדיקות e2e
npm run build:single             # יוצר את dist-single/index.html
npm run dev                      # או: שרת מקומי, http://localhost:5173
```

## עדכון לגרסה חדשה
כשיש אינטרנט: `git pull` (או ZIP חדש), אחר כך `install.bat`, ואחר כך `build-single.bat`. את הקובץ החדש `dist-single\index.html` מעתיקים במקום הישן.

## אם משהו לא עובד
- **"Node.js is not installed"**: מתקינים מ־nodejs.org, סוגרים את החלון ומריצים שוב.
- **התלת־ממד לא מופיע**: מפעילים האצת חומרה בדפדפן (ראו למעלה). בינתיים מוצגת הגרסה הדו־ממדית.
- **`npm install` נכשל**: צריך חיבור לאינטרנט בפעם הראשונה. מאחורי חומת אש של בית ספר כדאי לנסות מרשת אחרת.
- **הקובץ היחיד נפתח ריק**: פותחים אותו ב־Chrome, ב־Edge או ב־Firefox, לא בתצוגה המקדימה של מערכת ההפעלה.
