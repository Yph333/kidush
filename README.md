# בונים לוח עברי

אתר לימודי אינטראקטיבי על הלוח העברי: מחלק של שעה ועד חשבון הרמב״ם, עם זמני היום ומודלים בתלת־ממד.

## הפעלה
הכול רץ מקומית ובלי אינטרנט. רשימת ההתקנות המלאה והסבר צעד אחר צעד: [docs/OFFLINE.md](docs/OFFLINE.md).

**בלחיצה כפולה (Windows):**
- `install.bat`: מתקין את כל התלויות (פעם אחת). אם Node.js חסר, נפתח אתר ההורדה שלו.
- `build-single.bat`: בונה את כל האתר לקובץ אחד, `dist-single/index.html`, שנפתח בכל דפדפן גם בלי אינטרנט, ופותח את התיקייה שלו.
- `start.bat`: מפעיל את השרת ופותח את האתר בדפדפן. השרת נסגר לבד כשסוגרים את הלשונית, או אחרי 20 דקות בלי שימוש בעכבר או במקלדת. לשינוי הזמן: `start.bat --idle=45`.

**או בשורת הפקודה.** צריך Node.js 20 ומעלה. פעם ראשונה, בתיקיית הפרויקט:

```
npm install
```

**לעבודה ולהצגה במחשב:** `npm run dev`, ופותחים בדפדפן את הכתובת שמופיעה (בדרך כלל http://localhost:5173).

**קובץ אחד לשליחה או להקרנה בלי אינטרנט:** `npm run build:single`. נוצר הקובץ `dist-single/index.html`, שנפתח בלחיצה כפולה בכל דפדפן, גם בלי אינטרנט. הגופנים, המפות והתמונות כלולים בתוכו.

**אתר רגיל לשרת:** `npm run build`, ומעלים את התיקייה `dist/`.

### במהלך השיעור
- חצים במקלדת: חץ שמאלה = השקף הבא, חץ ימינה = הקודם.
- `P` מעבר בין מצב מצגת למצב חקירה · `N` הערות למורה · `F` מסך מלא · `Esc` סגירת חלונות.
- שנת ההדגמה והמקום נבחרים בשקף הפתיחה או בסרגל העליון, ונשמרים בכתובת: אפשר לשלוח קישור לשקף מסוים בשנה מסוימת.

### בדיקות ונתונים
- `npm test` בדיקות יחידה · `npm run e2e` צילומי מסך של כל השקפים (ב־`e2e/__screenshots__`).
- `npm run oracle:zmanim` נתוני ההשוואה מ־KosherJava (דורש Java) · `npm run horizons` פרופילי אופק מ־SRTM · `npm run sources:rambam` טקסט הרמב״ם מוויקיטקסט.

## איך מתחילים ב־Claude Code
1. פותחים את התיקייה הזו ב־Claude Code.
2. כותבים: **״קרא את CLAUDE.md ואת docs/SPEC.md, ותתחיל באבן דרך 1. קודם תציג לי תוכנית.״**
3. אחרי כל אבן דרך: בדיקות עוברות + צילומי מסך, ורק אז ממשיכים.

## מה יש כאן
- `CLAUDE.md` — הנחיות עבודה ל־Claude Code (באנגלית).
- `docs/SPEC.md` — האפיון המלא: פרקים, רכיבים, זמני היום, תלת־ממד, אבני דרך.
- `docs/VERIFICATION.md` — מקורות, כללי עיגול, ומה כל מנוע חייב להוציא.
- `tests/vectors.json` — נתוני האימות שהבדיקות ירוצו מולם.
- `legacy/` — אב־הטיפוס שעובד היום (`luach-v1.html`) והמנועים שלו.
