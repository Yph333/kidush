# בונים לוח עברי

אתר לימודי אינטראקטיבי על הלוח העברי: מחלק של שעה ועד חשבון הרמב״ם, עם זמני היום ומודלים בתלת־ממד.

## איך מתחילים ב־Claude Code
1. פותחים את התיקייה הזו ב־Claude Code.
2. כותבים: **״קרא את CLAUDE.md ואת docs/SPEC.md, ותתחיל באבן דרך 1. קודם תציג לי תוכנית.״**
3. אחרי כל אבן דרך: בדיקות עוברות + צילומי מסך, ורק אז ממשיכים.

## מה יש כאן
- `CLAUDE.md` — הנחיות עבודה ל־Claude Code (באנגלית).
- `docs/SPEC.md` — האפיון המלא: פרקים, רכיבים, זמני היום, תלת־ממד, אבני דרך.
- `docs/VERIFICATION.md` — מקורות, כללי עיגול, ומה כל מנוע חייב להוציא.
- `tests/vectors.json` — נתוני האימות שהבדיקות ירוצו מולם.
- `legacy/` — אב־הטיפוס שעובד היום (`luach-v1.html`) והמנועים שלו.
